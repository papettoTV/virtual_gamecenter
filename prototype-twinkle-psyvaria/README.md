# Virtual Game Center

オンライン上にゲームセンター体験を再現するためのプラットフォーム試作です。最初のゲームとして、弾幕かすり・無敵体当たり・ボス撃破型シューティング「BUZZ BARRIER（バズバリア）」を収録しています。

## ローカル開発

初回のみ依存パッケージとローカルD1を準備します。

```bash
npm install
npm run db:migrate:local
npm run dev
```

PCでは `http://localhost:5174/`、スマホではPCと同じWi-Fiにつなぎ、起動時に表示される `Network` のURLを開きます。ローカルとプライベートネットワーク内ではBasic認証を要求しません。

変更後の確認:

```bash
npm test
npm run build
npm run preview
```

## Cloudflare

フロントエンド、API、ランキング、筐体のリアルタイム通信を1つのCloudflare Workerへ統合しています。

- 静的画面: Workers Static Assets
- API: Cloudflare Workers
- 筐体ルーム・WebSocket: Durable Objects + Hibernation API
- ランキング・ゲーム結果・クレジット: D1
- ローカル実行: Cloudflare Vite plugin

本番反映時は、先にD1マイグレーションとBasic認証のSecretを設定します。

```bash
npm run db:migrate:remote
npx wrangler secret put BASIC_AUTH_USERNAME
npx wrangler secret put BASIC_AUTH_PASSWORD
npm run deploy
```

`npm run deploy` は本番公開を行うため、明示的にデプロイするときだけ実行します。

## 構成

- `src/app`: Reactの画面構成と起動
- `src/features`: ゲームセンター、筐体、ゲーム、ランキング
- `src/domain`: 筐体、ゲーム、結果、クレジットの業務ルール
- `src/realtime`: ブラウザ側WebSocket通信
- `src/worker`: Worker API、Durable Object、認証
- `src/games/graze-duel`: BUZZ BARRIER固有のルール、音、互換ランタイム
- `migrations`: D1スキーマ
- `tests`: ドメインルールとWorker統合テスト

詳細は [`docs/architecture.md`](docs/architecture.md) を参照してください。

## 遊び方

ローカル起動後は、ゲームセンタートップから `BUZZ BARRIER` を選び、筐体画面で `ゲームスタート` を押すとソロプレイが始まります。

ゲームを選ぶと `/cabinets/{識別子}` 形式の新しい筐体URLが発行されます。筐体画面の共有URLを別のブラウザまたはスマホでも開くと、先に筐体へ入った画面がプレイヤー、後から入った画面が観戦者になります。プレイヤーがゲームを開始すると、観戦者側の `観戦する` ボタンからゲーム状態をリアルタイムで確認できます。

- ローカル観戦は、自機とボスの軽量な位置更新、弾生成などのイベント、1秒ごとの全体キーフレームを組み合わせて同期します。
- 観戦側は受信した速度を使って弾を毎フレーム動かし、定期キーフレームとの差を滑らかに補正します。
- 途中から観戦しても、サーバーが保持した最新キーフレームと後続イベントから現在の画面を復元します。
- 通信が滞留した場合は中間の位置更新を省略し、弾生成イベントを優先します。
- 観戦画面からゲーム操作はできません。
- プレイヤーが筐体を離れると、観戦画面は筐体画面へ戻ります。

- 移動: 矢印キー / WASD
- スマホ移動: ゲーム画面内をタップし、その位置を中心にスライドした方向へ移動
- スマホ表示: 自分の画面を大きく表示し、相手は右上の情報HUDで表示
- スマホ操作: 画面下のリスタート/一時停止ボタンを使用
- 低速移動: Shift
- 攻撃: ゲージが溜まると自動発射
- 一時停止/再開: Space
- リスタート: R

## ルール

- 敵弾をギリギリで避けるとスコアとゲージが増えます。
- ゲーム開始直後は、少し間を置いてから弾が出始めます。
- 通常弾は、直進、狙い撃ち、斜め弾、3連弾、扇状弾、弾幕の壁、狙い連射など複数パターンがランダムに混ざります。
- 通常弾パターンは完全に毎回バラバラではなく、一定回数まとまって出てから次のパターンに切り替わります。
- スコアは倍率の影響を受けず、かすり1回ごとに固定値で増えます。
- クリア時はプレイスコアへタイムボーナスを加算し、合計スコアでランキングを競います。
- タイムボーナスは60万点から1秒ごとに1,000点減り、長時間のスコア稼ぎより早いクリアを優先します。
- かすった瞬間に短い効果音が鳴ります。
- 短い間に連続でかするとコンボになり、倍率が上がります。
- 最初はレベル1で、ゲージが満タンになるたびにレベルが1つ上がります。
- レベルが上がるほど、次のレベルアップに必要なゲージ量が増えます。
- レベルアップ直後は2.4秒無敵になり、無敵中のレベルアップでは0.4秒だけ延長されます。
- 無敵リングは残り時間に応じて小さくなります。
- 無敵終了直前の0.5秒は、リングが透明点滅します。
- ゲージが溜まると、効果音とともに自動で相手側に弾幕を送ります。
- レベルが上がるほど、攻撃時に送る弾の量が増えます。
- 攻撃弾のパターンは今後検討するため、現時点では従来の攻撃弾を維持しています。
- ボスはレベル到達ごとに登場します。
- レベル10で丸型のレベル1ボスが登場し、画面中央にじっとしています。
- 次の中ボスは、前のボスを倒した時点のレベル+10で登場します。
- 最後のラスボスも、中ボスを倒した時点のレベル+10で登場します。
- 中ボスは逆三角形で、左右にゆっくり往復します。
- ラスボスは星型で、左右に往復しながら上下にも細かく動きます。
- ボスには弾やかすりではダメージを与えられません。
- 無敵中のリングをボスに当てた時だけ、ボスにダメージを与えます。
- ボスを倒すたびに画面内の弾がすべて消え、次のボスが登場します。
- ボス撃破時は、数秒間ゲーム全体がスローになります。
- ラスボスを倒すとクリアです。
- 自機の当たり判定は中心の小さな点だけです。
- 自分のライフは3で、被弾するとライフを1失います。
- 被弾時は軽い爆発演出と効果音が出て、その後数秒間点滅しながら無敵になります。
- レベルが10上がるごとに、通常攻撃に加えて大きなボス弾を送ります。
- ライフをすべて失うとゲームオーバーです。

## 評価したいこと

- かすり続ける行為が気持ちいいか。
- 無敵中にボスへ突っ込む判断が気持ちいいか。
- ボスに攻撃するほど無敵が短くなる緊張感があるか。
- クリアを目指して「もう一度やりたい」と思えるか。

## デバッグ機能

- 敵弾量スライダーで、基本の敵弾量を1〜10段階で調整できます。
- 現在の通常量は `2 / 10` として設定しています。
- 自機の当たり判定トグルで、被弾あり/なしを切り替えられます。
- ゲージ増加難度の上下ボタンで、レベルごとの必要ゲージ増加量を調整できます。
- HUDに現在ゲージとレベルアップに必要な最大ゲージを表示します。
