# MOCHI BEAT / もちつきビート

「お手本を聞く → 同じリズムを返す」を繰り返すオリジナルのワンボタンリズムゲーム。うさぎ、背景、アイコンはコードで描画し、音楽と効果音はWeb Audioで合成する。外部音源・画像は使用しない。

- 操作: スペース / キャンバスのタップ / 「トン！」ボタン。Pまたは一時停止ボタンでポーズ。
- テンポ: 1セット目108 BPM、2セット目126 BPM、3セット目144 BPM。各セットは4拍カウントイン + 12フレーズ × 8拍。全体は約145秒（セット間の待機時間を除く）。
- 各フレーズ: お手本4拍、応答4拍。同じパターンを繰り返す。画面下には拍と休符の視覚ガイド。
- 3ステージ各4フレーズ: おひさま広場（四分音符）、夕やけピクニック（八分音符）、お月見パーティー（裏拍の組合せ）。
- 判定: ±65msは「ぴったり」、±160msは「おしい」、超過はミス。2・3セット目は拍の長さに比例して判定幅も縮める。最も近い未判定ノートを一度だけ判定する。
- スコア: `(ぴったり数 + おしい数 × 0.6 − 余分なタップ数 × 0.3) / 全ノート数 × 100,000`、四捨五入、下限0。全3セット132ノートを合算し、スコア・コンボを引き継ぐ。スコアにかかわらず3セット完走でゲームクリア。
- お手本中はタップしても減点なし。応答中の余分なタップは減点しコンボをリセット。
- 音声時計を音と判定で共有。120ms先まで予約し、タブ非表示・ウィンドウのフォーカス喪失時に自動停止。再開は同じ音声位置から。
- 音量は随時変更可能。タイミング調整は開始前に±200ms（10ms刻み）、端末へ保存。＋値は遅れて聞こえる音に合わせる。
- 既存のクレジット確認、ゲーム別ランキング、リトライに接続。1人用。ライブ観戦には未対応のためゲーム中の観戦共有ボタンは表示しない。

ゲーム登録には `0013_add_mochi_beat.sql` を適用する。本番への適用はデプロイ時に行う。

ローカルの動作確認: `/?game=mochi-beat&rhythmPreview=1`。開発ビルド限定でクレジットなしのプレビューと再試行ができる。プレビューからランキング登録はできず、本番ではこのパラメータは無効。


## もちの表現

- 開始説明に交代図と「聞く→まねする→交代する」を表示。お手本の4拍が終わってから、あなたの4拍が来ることを説明する。
- ぴったり: もちの中央が大きく凹み、横へ広がる。おしい: 浅く凹む。ミスの空振り: 凹まず小さく弾む。約0.46秒で元の形へ戻る。お手本でも大きく凹む。判定対象でないタップは成功の演出にしない。
- 完成もち: 80,000点以上は「とても美味しそうなもち」（ふっくら・つや・湯気・きらめき）、60,000〜79,999点は「美味しそうなもち」（丸い白もち）、60,000点未満は「まずそうなもち」（くすみ・いびつな形・ひび）。
- しきい値・説明・変形量・完成イラストは `src/games/mochi-beat/mochi.ts` にまとめてあり、採点を変えずに調整可能。
- 開発プレビューURLに `&mochiResult=excellent` / `standard` / `poor` を付けると各完成形を確認可能。`&mochiHit=perfect` / `good` / `miss` は変形の静止確認。どちらも開発専用で、ランキング登録なし。

### 終了の流れ

各セットの100拍目の境界で進行と入力・音を止める。最後の応答小節の表示位置を維持し、次の小節の先頭へ戻さない。1・2セット目では次のセットの説明（テンポ・累計スコア）を表示し、スペース／開始ボタンが押されるまで待機。次セットで追加クレジットは不要。3セット目の後に完成もちをゲーム画面中央に3.5秒表示してから、成績画面を0.45秒でフェード表示する。非表示タブの時間は完成もちの表示時間に含めない。完成形の開発プレビューも同じ終了演出を通る。

3セット版のランキングバージョンは `mochi-beat-sets-2`。旧1セットの記録と表示を分離する。開発プレビューの `&mochiSetEnd=1` / `2` でセット間の説明から動作確認できる。
