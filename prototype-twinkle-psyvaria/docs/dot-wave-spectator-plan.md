# DOT WAVE 観戦企画

目的は「すごいプレイが見て分かる」「逆転を見届けたい」「自分も挑みたい」を作ること。ゲームのテンポを止めず、文字に頼りすぎない演出を基本とする。

## 1. 良い攻防で曲が育つ（3段階の試作）
攻防の成功に応じてドラム・ベース・メロディーを重ね、会場も華やかにする。強い2人の対戦ほど、聴いていて楽しくなる。判定に必要なお手本音が埋もれないようにする。

### 試作仕様
- 通常（拍とキック）→ベース追加→伴奏追加の3段階。操作・攻守交代・ダメージ・難易度は変更しない。打ち返しは使わない。
- 攻撃・防御それぞれの精度が0.55以上なら盛り上がりを1加算。最大4。2でベース、4で伴奏を追加する。「おしい」中心でも育つ。
- 両者とも基準に届かない攻防が2回続いたら2減らし、1段階ずつ静かになる。一度のミスでは音を消さない。
- 確定した攻防結果を使い、次の攻防で準備4拍を終えた、お手本開始の区切りで音を追加・削除する。両者・CPU・観戦者で同じ結果から同じ段階を再現する。
- 音楽は既存の音声時計とBPMでスケジュールする。ベースにはオクターブの矩形波を重ね、伴奏には3音の和音・明るい8分音符のフレーズ・打楽器風の音を追加する。操作する4〜12拍の間は追加音量を65%に抑え、お手本・タップ音を聞き取りやすくする。
- ベースで床がネオンのタイルになり、スピーカーと上部のラインが光る。伴奏で床の光を増やし、左右の段状スポットライト、大きなイコライザー、ドットのきらめきを追加する。中央の難易度演出や手番の合図は変えない。盛り上がりゲージや追加説明UIは置かない。
- 新しいゲームでは通常から開始。判定や対戦成績とは独立した演出として調整する。

## 2. 完全防御で打ち返す（企画）
音符コメットを完全防御すると、色が変わって相手へ跳ね返る。ラリーが続くほど巨大化し、文字がなくても攻防が伝わる。通常の攻守交代と区別する専用の音・演出が必要。

## 3. ピンチからの覚醒（企画）
残り体力が少なくなるとキャラの芯が強く光り、難しいリズムを成功させることで一度だけ強い反撃を放つ。「ここから逆転できるか」を観戦の見どころにする。発動条件と強さは要検討。

## 4. 連勝チャンピオン（先行実装）
勝ち残った人に王冠を付け、連勝で見た目と入場演出を豪華にする。プレイヤーには連勝を見せる楽しさ、観客には応援・挑戦する相手を作る。既存の観戦からの挑戦・勝者の席残留を利用する。

### 初期仕様
- キャラに対応する位置にプロフィールのプレイヤー名を表示。CPUは「CPU」。観戦者にも両者の名前を表示する。
- 名前は既存プロフィール編集で変更する。未登録の人も既存のゲスト名を使う。公開するのは表示名で、アカウントID等は送らない。
- 連勝はこの筐体に参加し続けている間の対人戦勝利数。CPU戦では増減しない。
- 勝者は連勝+1、敗者は0。挑戦者が勝てば1勝から王冠を獲得し、席移動後も維持する。
- 引き分けは連勝数を維持。席を離れると終了。再接続は従来どおり新しい参加として扱う。
- 対戦開始後の切断勝利は加算する。準備中に中断した場合は加算しない。
- 王冠は1勝、3連勝、5連勝で3段階。名前・連勝数・王冠は両プレイヤーと観戦者へ同じ内容を配信する。
- 勝敗確定時の連勝更新はサーバーで一度だけ行い、結果の重複送信で加算しない。
- 結果を閉じるまで勝者側の画面は維持し、連勝演出で勝手にゲームを開始しない。
- 永続ランキングや別筐体へ持ち越す連勝記録は今回の対象外。

## 5. 観客の応援が会場を彩る（企画）
観客が拍に合わせて応援を押すと背景に小さな光が点灯し、集まると花火になる。勝敗や判定には影響させず、観戦でも参加感を得られるようにする。プレイを妨げない明るさ・頻度を検討する。

4を実装後、2は試作して取り消し。現在は1の3段階版を試す。2・3・5は企画メモとして保持する。
