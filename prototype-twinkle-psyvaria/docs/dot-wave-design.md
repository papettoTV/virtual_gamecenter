# DOT WAVE — ドットの電光アリーナ

採用イメージ：`concepts/rhythm-battle/dot-wave.png`。
入口 `/labs/dot-wave`。旧 `/labs/mochi-duel` も互換入口として残す。

## 表現

- 黒紫の背景に、シアン #13e5f3・ピンク #ff39bc・ライム #baff39。
- キャラクター、音符、中央コア、スピーカー、床を隙間のある四角いドットで描く。
- ロゴは専用の5×7文字パターン。開始前の説明と操作名は残し、プレイ中の状況説明・NEXT / NOW・SYNC / GOOD / MISSは画面に出さず、読み上げ用の説明として残す。
- ドット絵は `DotScene.tsx` のSVG矩形として描画。画像生成したコンセプト絵を画面に貼り付けず、ゲーム状態に反応するパーツとして実装。
- 成功時はキャラクターのジャンプときらめき（良い判定ほど大きい）、音符パルス、ガード時の粒の散開。ミス・入力抜けは灰色のしょんぼりしたキャラと、崩れ落ちる音符・低い音で伝える。
- HPは数値とバー、太陽は音符コア。難易度を数値表示せず、コアの放射状の光が伸びる。勝負終了はFINAL WAVE / KNOCKOUT。
- 専用アイコン `public/assets/dot-wave-icon.svg`、ブラウザタイトルもDOT WAVEへ変更。
- 人が操作するキャラの上に「押す手＋下向き矢印」。次の番は約1秒周期で点滅し、今の番は点灯。操作ボタンにも同じ手を表示する。動きを減らす設定では点滅を控える。
- CPU側には番の枠や手の合図を表示しない。CPUの準備・攻撃・防御中はリズムバーを囲むピンクの枠も表示しない。同端末2人対戦では両方の人に合図を出す。
- 攻撃力アップの緑の丸とCHARGED文字を廃止。キャラの横に点滅しない金色の音符と上向き矢印を置き、強化中に飛ぶ音符も金色・大きめにする。
- 相手の番の入力は黄色の「待って」の手・キャラとボタンの短い揺れ・小さな二音で案内。警告は約0.75秒、または自分の入力受付開始で消し、追加の減点はしない。マウス・タッチ・キー共通で、直前入力の許容幅は維持する。
- ダメージや拍などの数字は残す。攻撃／防御は音符／シールドのアイコンで表す。
- 自分の攻撃前は音符＋4・3・2・1、相手の攻撃中は自分の防御に向けてシールド＋4・3・2・1を表示。CPU用のカウントダウンは出さない。同端末2人対戦では次に操作する側の色で予告する。

## 音

`audio.ts` のWeb Audio合成。追加音源・外部フォント・外部サービスへの依存なし。

- 方形波の短いパルスをお手本・タップ音に使用。
- 三角波の低音で拍を支える。
- SYNCは高音を重ね、GOODは単音、MISSは低い下降音。
- 防御は攻撃より高い音域。完全防御・難易度上昇は上昇アルペジオ。
- 被弾は短い低音、勝利は上昇音、敗北は下降音、引き分けは往復音。
- 全て共通の音量ゲインを通る。一時停止はAudioContextごと停止し、終了時に演奏を止めて結果音を再生。

## 維持するルール

自動ランダムパターン、4攻防ごとの難易度上昇、準備4拍→攻撃4拍→防御4拍の連続進行、CPU戦の2種類の終了方式を維持する。通信対戦はレベル1からFINAL WAVE方式で開始する。
ソロの「もちつきビート」は別ゲームとして残し、ゲーム一覧と筐体内のリンクからDOT WAVEへ案内する。通信対戦では自分側だけに合図を出し、観戦画面には操作ボタンを出さない。
