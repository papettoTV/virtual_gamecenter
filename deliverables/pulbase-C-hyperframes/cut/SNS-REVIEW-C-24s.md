# C案24秒：SNS向け構成レビュー

判断：構成・情報の読みやすさについて試作レビュー合格。視聴維持率や訪問率は配信実測前のため未検証。

| 観点 | 確認内容 | 判定 |
|---|---|---|
| 冒頭の具体性 | 1秒以内に友だちのプレイ招待・挑戦者募集が届く。知り合いの観戦URLが入口 | 合格 |
| 読める速さ | 招待文は約4秒保持。中央コピーは3.9〜5.45秒。中心を一定速度でゆっくり通過 | 合格 |
| 観戦者の物語 | 休憩 → URLを開く → 実際の弾幕に見入る → 挑んでみたい → 申し込み → 承認 → 自分のプレイ | 合格 |
| 操作の理解 | メッセージとリンク押下、挑戦ボタンの押下反応、申込済み、承認を別々に表示。字幕とボタンが重ならない | 合格 |
| 対戦の理解 | 同じ実試合の上＝相手／下＝自分。別の弾幕と自機の動き。対戦開始は文字表示 | 合格 |
| 訪問への導線 | 対戦映像を止めずPULBASE・まずは観戦してみよう・pulbase.comを表示。ブランドは冒頭のURLカードにも出る | 合格 |
| 誇張の回避 | 勝利・ランキングの架空結果なし。メッセージ、ボタン、上下分割は動画内で演出と注記 | 合格 |
| 無音での理解 | 音楽・効果音・ナレーションを前提としない。映像と操作の変化で流れを示す | 合格 |

## 制作上の限界
実録素材の元収録fpsは観戦約16fps・対戦約9.8fps。30fpsに実時間で再標本化したため、構成確認用の試作であり、60fps等の本番収録品質ではない。補間・速度変更・弾の追加加工は使用しない。
実サービスの画面そのままの収録ではなく、実録ゲームに読みやすい広告用UIを重ねたもの。機能の細部を断言しない。

## アクセス先の確認
リポジトリREADMEの本番カスタムドメインpulbase.comを使用。2026-10-13に公開トップページとBUZZ BARRIERの案内表示を確認した。ただし、このブラウザーでは「プレイヤー情報を読み込めませんでした」が再読み込み後も表示された。動画制作の範囲ではサービス本体の修正・公開は行わない。SNS公開前に実利用環境で確認する事項として記録。


## 冒頭背景とラストコピーの修正

ラストは「すぐ遊べる。観戦から、対戦も。」。サイトから直接遊べることと、観戦が対戦にもつながることを表す。観戦を必須の順序として示さない。冒頭の無地のグレー背景を、架空の古き良きゲーセンの画像へ変更。背景だけゆっくり寄り、招待文・リンク・操作を読みやすく重ねる。人の顔・手なし。背景が演出であることを動画内で注記。24秒、無音、申し込み・承認と実対戦の上下2分割は維持。
