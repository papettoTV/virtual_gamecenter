# サイト配布から除外した制作素材

2026-11-03、運営者のR-05承認により、制作原本・制作プレビュー・旧デモ・非採用アイコンの8ファイルを`apps/web/public/`から移した。元の相対パスを維持し、内容を変更せずGitで保管する。サイトの静的配信ディレクトリではない。

対応する旧パス・サイズ・SHA-256は`manifest.json`に記録し、移動前の`docs/public-asset-audit-2026-11-03.json`と照合する。旧MP4の音声検査記録も維持する。再配布したい場合は用途を再確認し、配布台帳・テストを更新する。

Blender生成スクリプトは原本と制作プレビューをここへ出力する。実行時のGLB・manifest・図鑑PNGや現行デモ・SNS画像は引き続き`apps/web/public/`に置く。非採用MOCHI BEATの定義は公開ゲームカタログに含まれず、保管アイコンを配布へ戻す理由にはしない。

これは次回ビルド以降の配布対象を変えるもので、既に公開されたCDN上のファイルやキャッシュの削除を実施した記録ではない。本番操作・デプロイ・キャッシュ削除は行っていない。
