# BUZZ BARRIERのスマホ用ステータス行

スマホプレイ表示では、52pxの独立した停止ボタン領域と中央寄せを廃止し、セーフエリア内の上端にゲーム枠を揃える。停止ボタンは既存のDOM・イベント処理を維持し、ステータス行の右端に44×44 CSS pxのアイコンとして表示する。再開時は▶とアクセシブルな名前「再開」に切り替わる。スコア・経過秒・レベル・倍率・コンボ・残機を表示し、攻撃ゲージは行下端のmeterとして残す。プレイヤー名とゲージの数値・自動攻撃状態もアクセシビリティ属性に保持する。

ゲーム枠の416:640、Canvasの960:640、2D/WebGLの共通変換、シミュレーションと当たり判定には変更を加えない。縦方向だけの拡大や敵領域の追加は行わない。従来の8px余白をセーフエリアの実寸に置き換えるため、縦長画面では横幅の拡大もゲーム領域の高さに還元される。セーフエリア0の390×844なら枠高は約575pxから600px、844×390なら322pxから390pxとなる。縦長画面で比率を保って表示できない残りの高さは余白となる。通常表示・PC・観戦・他ゲームは従来のCanvas HUDを使う。
