## UIレポートの保存先

PR #87のブラウザケースは成功したが、独立レビューでreport.jsonの欠落が指摘された。
JSON／HTML reporterの出力先は設定ファイルの位置から相対解決される。
`ci/ui-local.config.mjs` で `ci/ui-results/...` と指定していたため、実ファイルが `ci/ci/ui-results/...` に生成されていた。
成果物対象の `ci/ui-results` には入らず、レビューへ渡せていなかった。

出力先を `ui-results/...` へ修正し、ブラウザ検査成功後に成果物対象のJSONとHTMLが存在することをCIで確認する。
一時コピーのPC・スマホ相当の実ブラウザ2件を実行し、古い期待先のファイルを削除した状態から、JSON・HTML・画面2件が正しいフォルダへ新規生成されることを確認した。
これはIssue固有の受け入れ確認や本番での回帰ではない。
