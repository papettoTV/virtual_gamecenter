# 無料ベータ公開前のセキュリティレビュー

更新：2026-10-14。EN-03の点検を継続。検証環境が対象で、本番公開の承認・包括的な監査完了ではない。

## 今回の確認と修正

| 対象 | 確認・対応 | 証跡 |
| --- | --- | --- |
| ログイン後の残高 | Chromeの検証サイトで5枚表示、ログアウト後0枚のゲストへ切り替わり、再ログインで元の5枚に戻る | 実ブラウザ操作と検証D1の読み取り照合。登録特典は1回・5枚で二重付与なし |
| ログアウト | トップへ遷移、登録者向け操作とログアウトボタンが消える | 実ブラウザ操作。自動テストでは旧セッションのプロフィール変更が401になることも確認 |
| ログイン通知 | 既存ユーザーにも「登録完了・5枚追加」と表示する不具合を修正 | 認証結果を新規登録・特典なしの再登録・既存ログインに分離。実際の台帳挿入結果に基づいて通知 |
| API/観戦接続のOrigin | 更新API・WebSocketに共通の入口検査を追加 | staging/productionでは同一Origin必須。別サイト・本番サイトから検証サイト・null・Origin欠落を403。ローカルのOrigin欠落は既存テスト/CLIのため許容し、明示した別Originは拒否 |
| 決済Webhook | ブラウザOrigin検査の例外とし、既存の署名検証を維持 | Origin欠落が同検査で拒否されず、署名なしは成功しないテスト |
| 個人の残高レスポンス | platformJsonにprivate, no-storeを指定 | bootstrapレスポンスのヘッダー検査 |
| 環境分離 | Pagesの環境ヘッダー上書きとWorkerの不一致拒否を維持 | 既存gateway統合テスト |

Origin検査はブラウザからの意図しない操作を防ぐ境界であり、Originを偽装できるHTTPクライアントへの認証や乱用対策の代替ではない。WebSocketの101応答は従来どおり透過する。[Cloudflare WebSockets公式資料](https://developers.cloudflare.com/workers/runtime-apis/websockets/)も参照。

## 未完了の点検・対応

### 2026-10-14：既存WebSocketのセッション失効

- 接続時に検証済みセッションのハッシュをattachmentに保存。Cookieの生トークンは保存・配信しない。
- ログアウト時に該当プレイヤーの既知の筐体へ失効RPCを送り、同じセッションの接続のみ退出/1008で切断。他端末の同一ユーザーと、他ユーザーの観戦接続は残す。
- 操作メッセージではDBのセッション有効性と削除状態を再確認。高頻度のライブフレームだけは最大5秒キャッシュし、毎フレームのD1照会を避ける。旧attachmentはハッシュを持たないため操作時に閉じ、再接続を必要とする。
- ISO形式の期限とSQLiteのCURRENT_TIMESTAMPを文字列比較すると同日内の期限切れを取り逃がすため、HTTPとWSの判定をdatetime(expires_at)で日時比較するよう修正。同日内の1分前をISO形式で設定する回帰テストを追加。
- 匿名の観戦は維持し、匿名のプレイヤー席取得は拒否。JSONのnull等の不正形式も例外ではなくエラー応答にする。
- テストで複数筐体の同一セッション切断、他端末/観戦者の継続、DB上の失効、不正形式、匿名観戦を確認する。退会時の接続切断は既存テストも継続する。
- 接続受理とログアウトの競合、RPC失敗時の扱い、自然期限切れのアイドル観戦接続は追加点検が必要。失効キャッシュの最大5秒は「全状況で即時切断」とは異なる。
- 全459テスト（Vitest434件＋解析11件＋公開設定14件）、型検査・検証ビルド成功。検証Worker version `1cdcca0c-6289-49f6-9ebb-5d5c1636bb6d`へ反映済み。
- 実develop Pagesで専用ゲスト1件の期限だけを変更し、期限切れHTTPが401・既存WSが1008で切断・匿名観戦者の接続維持を確認。通常の消費/ゲーム開始/観戦フレーム配送も再確認。既存利用者のセッション・本番DBは変更していない。

### 点検で見つかった公開前の優先課題

`startSolo`と対戦予約のサーバー側検証がDOT WAVEに偏り、他ゲームでは所有者・消費済み予約を全操作で確認していない。HTTPでクレジットを消費してから開始する通常UIだけでは、直接WebSocketを操作する利用者の不正を防げない。全ゲーム共通の予約検証・再利用防止を次のEN-03作業とし、解消するまで公開判定を完了にしない。

2026-10-13の修正は検証Workerへ反映済み。全455テスト・型検査・検証ビルド成功。反映後のGoogle再ログイン通知/残高/ログアウトと、専用ゲストのゲーム開始・ライブ観戦同期を実環境で再確認した。実APIでも不正Origin4種類を拒否し、個人レスポンスのno-storeを確認。本番には反映していない。

1. 筐体の役割ごとの全メッセージ、所有権、ログアウト/退会後の既存WebSocket権限を検査する。
2. API本文とWebSocketメッセージのサイズ上限を統一し、接続数・筐体数・無料特典の乱用を制限する（EN-04）。
3. OAuth失敗ログ、セッション・個人情報、URLクエリを含む外部ログの保持/マスキングを確認する。
4. 結果登録のプレイとの紐付け、重複登録、クライアント申告値の不正対策を検証する（EN-05）。
5. Basic認証の比較方法、個人API全体のキャッシュ方針、セキュリティヘッダーを点検する。
6. 本番リソース設定、復元、監視・通知、PC/iPhone/Androidの実機検証を別途実施する。

重大な未解決事項を残したまま、EN-03や無料ベータ公開判定を完了にしない。
