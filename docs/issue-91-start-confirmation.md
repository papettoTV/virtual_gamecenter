# Issue #91 開始確認の順序

BUZZ BARRIERと深海サルベージは、筐体への入場時には開始待機画面だけを表示する。`start=1`も開始了承として扱わない。開始ボタンまたは対応キー（BUZZ BARRIERはSpace、深海はP）でクレジット確認を開き、了承後に既存の予約・消費確定・サーバー開始認可を成功させて実プレイへ進む。キャンセルとEscは待機に戻る。

DOT WAVEも従来は開始待機画面そのものに消費確認を表示していた。開始ボタンまたはSpaceの後に独立した確認を開くよう変更した。了承後は既存のbeforeSoloによる予約・消費確定・開始認可を経てカウントダウンへ進む。CPUの次ステージへの進行とポーズ解除は追加課金しない。

料金・配布・返却ルールとサーバー認可は変更していない。スマホ全画面表示・回転時の入力処理も維持する。
