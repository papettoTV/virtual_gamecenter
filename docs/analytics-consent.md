# Google Analyticsの同意・拒否（無料ベータ）

## 方針

- Google Analyticsだけを対象とする任意の選択。規約承諾・ログイン・無料クレジット・プレイ・観戦の条件にしない。
- 未選択・拒否・期限切れは停止。同意までGoogleタグを読み込まない基本的な制御方式。拒否時のCookieなし計測信号を送るAdvanced Consent Modeは使わない。
- 全アプリ画面に非モーダルの案内を置く。同意・拒否は同じ強さのボタンとし、閉じても解析は開始しない。フッターから再設定可能。
- `pulbase.analytics-consent.v1` に選択と日時を180日間保存。端末・ブラウザ単位で、アカウントとは独立。ログアウトでリセットしない。削除・退会によって保存を消した場合も、未選択として停止する。
- localStorageが使えない場合は現在のページだけ選択を保持。他タブの保存変更・削除を反映。期限切れ時に再案内する。
- ローカル・LAN・fileおよびiframeでは、同意してもタグを読み込まない。
- Pages経由の検証Workerは解析停止フラグを付加する。developの実ホストでもGoogle Analyticsを読み込まず、本番の計測に混入させない。

## 撤回

拒否に変更すると `ga-disable-G-0SLPCHD77R` を有効化し、送信待ちキューを破棄し、サイトから削除できる `_ga` / `_ga_*` Cookieを削除する。ゲームの状態・認証Cookie・残高を触らず、リロードもしない。読み込み済みプログラム自体は残る。送信済みや通信中のデータの削除・取消しではない。再同意時は設定を再投入し、タグを重複ロードしない。

## 送信の最小化

手動page_viewのみ。筐体URLは `/cabinets/live`、結果URLは `/results/shared` に正規化し、クエリ・ハッシュ・個別IDを送らない。タイトルはPULBASE、参照元は空欄。プレイヤーID・メール・公開名・残高を付加しない。広告目的の同意・Google signals・広告パーソナライズは無効。GA Cookieは180日、期限更新なし。

サービス内の共有・流入記録はGAと異なる仕組みであり、この選択では停止しない。その目的と保存期間はプライバシーポリシーで別途説明する。
