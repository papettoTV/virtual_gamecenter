# フィードバックの運営者閲覧

`/operator/feedback`（HTML）と `/api/operator/feedback`（JSON）は、staging / production の各環境に設定された `OPERATOR_ACCOUNT_IDS` に含まれる、有効なGoogle連携アカウントだけが閲覧できる。未設定は503、未ログイン・失効・削除要求済みセッションは401、許可対象外・ゲスト・開発者ログインは403。未知の環境は404となる。

ローカルでは従来どおり、ループバックホストかつ開発者認証が有効な場合の開発者ユーザーだけを許可する。LANからの閲覧は許可しない。`/operator/operations` とそのJSON APIはstaging限定で、本番のフィードバックHTMLには集計画面へのリンクを表示しない。

本番の許可対象確認と本番専用 `OPERATOR_ACCOUNT_IDS` Secret登録は、運営者が別途行う。検証用の設定・アカウントを流用せず、ID・メール・Cookie・Secret値をコードや公開証跡に記録しない。この実装では環境設定、Pagesゲート、DB移行、Secret登録を変更しない。

マージ前は使い捨てDBと架空のアカウントによるHTML/JSONの成功・拒否回帰テストと検証ビルドを確認する。マージ後のCI・独立レビュー、develop反映、検証公開SHAと認可動作の確認は別の証跡とする。その後、運営者承認を伴う既存本番公開フローを経て、許可された本人が本番一覧を確認する。公開後の記録には対象SHA・確認日時・成否を残し、フィードバック本文や個人情報は添付しない。ローカルテスト成功を公開後の確認済みとして扱わない。
