# DOT WAVEのソロ再挑戦・観戦確認

更新日：2026-10-21。対象は[Issue #22](https://github.com/papettoTV/virtual_gamecenter/issues/22)、チェックリストBT-02/BT-03。

## 調査対象と結論

以前のPC確認で、リトライ中に一度だけプレイヤーが観戦役へ変わった。今回の通常リトライと開始直後の複数キー入力では再現していない。原因の特定・不具合修正済みとはしない。推測に基づく役割の強制変更や、クレジット・接続制限の緩和は行わない。

## 検証環境の実画面確認

反映済み基準版 `d5f9f4e20224fcdc197d89418f9881652a174d2f` の検証サイトで実施。プレイヤーは運営者が新しく開いたChromeシークレットの専用ゲスト。観戦は別Cookieの通常Chromeを読み取り専用で使用し、対戦・登録・購入は行わない。通常ログインのクレジットを消費しない。古いシークレットゲストは残高0だったため使用せず、運営者がウィンドウを閉じて新規環境を準備した。

| ケース | 結果 |
| --- | --- |
| 解析拒否→DOT WAVE選択→初回特典受取 | 成功。サイト訪問のみでは特典を強制せず、START時に受取導線を表示 |
| 初回START→自然終了 | 成功。プレイヤー席維持、10攻防、0対100、残高5→4 |
| 別CookieのURL観戦 | 成功。プレイヤー名・攻防・終了結果が一致。観戦画面にRETRYは出ない |
| RETRY→Space/F/Spaceの連続入力→再開始 | 成功。プレイヤー席を維持し、残高4→3。観客1人を維持。役割変化は再現せず |
| 再開始後のP停止・再開と観戦同期 | 成功。攻防6/10で双方PAUSED。観戦側のPでは再開されず、プレイヤーのPで再開 |
| 再挑戦の自然終了→退出 | 成功。双方10攻防・3対100で一致。プレイヤーがゲーム一覧へ退出後、観戦側は開始待ち/終了表示へ移行 |

この表は上記経路だけの確認であり、全クリア・ランキング・実音声の品質・通信切断復帰・Windows/iPhone/Androidの合格ではない。最終PRの検証反映後の再確認と公開SHAは、Issue/PRの証跡に別途記録する。

## 追加した自動回帰テスト

- コントローラー：終了→再予約→開始許可の間もplayer/side 0を維持し、予約・確定は各プレイ一度、join一回・leaveなし・待機タイマー残存なし。
- ローカル実DO：同じホスト/観戦接続で終了フレーム→新規予約で再開始→新しいプレイフレームを配信。席1・観客1、ホスト残高3・観戦残高5、退出後の空状態を確認。

対象コントローラー9件、DOT WAVEの実DO18件は成功。標準の全体実行は既存のアドレス上限テストで2回5秒タイムアウトし、当該ファイルの単独11件は成功した。ローカルの実行時並列数を2に抑えた全Vitestと、`npm test`に含まれる後続スイートをすべて実行し、合計831件成功。制御系32件・ワークフロー検査・型検査を含む検証ビルドも成功した。CPU競合の影響は疑われるが原因は断定しない。テスト内容・時間制限・除外・CIの並列設定は変更していない。通常の`npm test`・DOT WAVE安定性3回は必須CIで別途確認し、CI失敗ならマージしない。

## 残す課題

- 以前の役割変化は原因未確定。再発時は開始/終了/再挑戦の順序、他タブの有無、切断表示、対象リビジョンを記録する。Cookie・認証値をログに残さない。
- 未確認の端末・全クリア・ランキング・切断復帰は元のPC確認記録どおり残す。
- 負荷試験と保留中の接続回復コード、本番/main、DB移行、監視通知設定は対象外。通常操作の成功を30分試験の合格・無料ベータ公開承認へ変更しない。
