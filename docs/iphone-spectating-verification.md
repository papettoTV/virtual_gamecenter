- 検証先は `https://develop.virtual-gamecenter.pages.dev/` のみ。
- Worker / Pagesのリビジョンはともに `cb2295fbd2233634004719065400e554c86f1463`。実機は「iPhone検証用」、iOS 26.6.1、Safari。USB列挙の機種コードは `iPhone13,1`。

## Issue #33の改善

- BUZZ BARRIERの観戦READY/PAUSEDは、プレイヤーの開始/再開待ちにする。観戦者に開始ボタン・移動キー等を案内しない。
- 深海サルベージも開始待ち、ポーズ、図鑑の観戦説明を役割に合わせる。HUD下部の開始操作案内も対象。
- 820px以下の観戦画面ではHUD上の重複した共有アイコンを隠す。上部の「このライブを共有」は残し、PC・プレイヤー側の共有機能と観戦スクロールは維持する。
- ローカル回帰テストとビルドの結果、検証への反映/修正後実機確認の状態はIssue/PRに追記する。上の修正前実機結果を修正後の確認完了として扱わない。
