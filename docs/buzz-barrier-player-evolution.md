# バズバリアの自機進化境界

現在の見た目の進化は、共通判定 `getPlayerShipStage`（`apps/web/src/games/graze-duel/rendering/player-ship.ts`）で決める。

| レベル | 段階 | 形状 |
| --- | --- | --- |
| 未指定・0〜29 | 第1段階 | 基本形。レベル10では進化しない |
| 30〜59 | 第2段階 | 縦長コアと左右ブレード |
| 60以上 | 第3段階 | 固定コア、前後軸で回る立体の翼、鋭い裾のスカート |

Three.jsとCanvasは同じ共通判定を使い、観戦・CPU・対戦相手も描画対象のレベルに従う。リスタートでレベル0へ戻れば基本形に戻る。

各段階の形状、最大表示範囲34×37、当たり判定・かすり判定、移動速度、シールド・稲妻・音、翼だけの回転軸・周期（2.4秒）・隙間、スカートの裾は従来どおり。ボス出現レベルなどのゲーム進行条件はこの境界とは独立している。

`apps/web/docs/graze-duel-player-evolution.md` は初期設計の履歴であり、現在の境界は本書を参照する。
