# DOT WAVE 上部余白の調整（Issue #82）

## コード上の比較と変更

- 比較対象は BUZZ BARRIER の通常ページ（共通 `.shell` と `.spectator-banner`）。共通シェルの上余白は PC 28px、820px以下のゲーム画面では8px。筐体情報から次の領域までは12px。
- DOT WAVE は独立したページで、筐体バーの上マージン18px（600px以下12px）に55pxの上パディングが加算され、さらにタイトル側の上マージン18px（600px以下12px）があった。
- 筐体バーの上パディングをPCで16px、820px以下で10pxとし、セーフエリアが大きい場合はその値を優先する。820px以下の筐体バーの上マージンは0。タイトル側の上マージンは10pxに統一する。
- 固定アカウントボタンとの重なりを避けるため、筐体バーの右側にPCで64px、820px以下で60pxと右セーフエリアの合計を確保する。アカウントUI自体は変更しない。
- 開始前・プレイ中・ALL CLEARを含む結果表示で同じ筐体バーとタイトル間隔を使う。結果カード、ランキング登録、リトライのコードは変更しない。
