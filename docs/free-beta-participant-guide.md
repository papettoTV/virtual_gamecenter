# 無料ベータの参加案内・フィードバック手順（公開前下書き）

更新日：2026-11-02 / Issue #36

一般公開ベータを想定した案内。知人5名の確保や招待5→10名を公開条件にしない。本資料の作成は、本番公開・アクセス制限解除・告知送信の承認ではない。未確定事項を残したまま告知しない。

本資料で人数上限・待機列・自動停止機能を新設しない。同時6人という過去の案は性能保証でも実装された制限でもなく、一般公開の定員として使わない。

## 参加者向けの説明

### 何を楽しめるか

PULBASE（パルベース）は「本気のプレイが、人を呼ぶ。」を目指す、オンラインのゲームセンターです。動くゲーム画面を見て回り、ライブを観戦したり、自分でも挑戦したりできます。

- BUZZ BARRIER、DOT WAVE、深海サルベージのソロプレイとライブ観戦が対象です。
- 観戦・ゲストプレイのためのログインは不要です。Googleでのユーザー登録は任意です。
- 登録すると残高を別端末で利用でき、ランキング名を設定できます。ゲスト名はシステムが付ける固定名です。
- 有料クレジットの購入、対戦・協力、チャット、リプレイは無料ベータの提供対象外です。
- ベータのため、不具合・一時停止・仕様変更があり得ます。端末別の確認範囲は下表を参照してください。
- 無料ベータでは年齢・居住地域による参加条件を設けません。未成年の方は保護者と利用条件を確認し、法令上必要な場合は同意を得て利用してください。

### 端末・ブラウザの確認範囲

| 環境 | 記録で確認できたこと | まだ保証しないこと |
| --- | --- | --- |
| Mac / Chrome | 過去の検証版で3ゲームの通常プレイ・終了・観戦。DOT WAVEの再挑戦と実iPhoneとの同期も確認 | 公開候補版の全クリア・全ランキング・実音声品質・通信切断復帰を網羅した保証 |
| iPhone / Safari | 過去の検証版で3ゲームのライブ観戦・スクロール・終了表示。#72では3ゲームのプレイ結果・フィードバック導線も確認 | iPhone全機種、横向き・音声・発熱・回線切替、スマホプレイ全般の対応保証 |
| Windows / Chrome、Android / Chrome | 今回照合した記録では実機確認が不足 | PC画面幅の変更や自動試験を実機確認の代用にしない |
| その他・SNS内ブラウザ | 初回は動作確認の対象外 | 問題があれば通常のChrome / Safariで開くよう案内する |

これは過去の実施記録の要約で、対応保証や公開合格表ではありません。B-02の表記方針は確定していますが、公開候補版での再確認は残ります。[端末別確認計画](free-beta-scope-and-device-checks.md)を参照してください。

### 無料クレジット

| 内容 | 現行仕様 |
| --- | --- |
| 初回プレイ特典 | 受取画面で無料5枚。閲覧・観戦だけなら受取不要です。初回付与は一度限りです |
| 初回ユーザー登録特典 | 初めて登録すると追加5枚。初回受取分と合わせて計10枚。ログアウト・再ログインで繰り返し付与されません |
| 毎日の補充 | 初回特典等の無料付与履歴がある利用者が対象。日本時間の日付ごとに、利用時の残高が3枚未満なら3枚になるまで不足分を補充します |
| 補充の例 | 0枚なら3枚、1枚なら2枚、2枚なら1枚。3枚以上は加算も減額もせず、実際に補充するのは1日1回。未訪問日の分は貯まりません |
| 1プレイ | 新しいプレイに1枚。終了後のリトライにも1枚。確認画面でキャンセルしただけでは消費しません |
| 観戦・購入 | 観戦はクレジット不要。無料ベータ中は購入できません |

補充済みで残高がなくなった場合は翌日の補充を待つか、未登録なら初回登録特典を利用できます。ゲストの識別はブラウザの保存情報に依存し、Cookie／サイトデータ削除やプライベートブラウズ終了で同じゲストへ戻れなくなる場合があります。

開始前キャンセルと開始後の退出・通信障害では返却条件が異なります。「不具合なら必ず返却」や「描画前なら必ず未消費」とは案内しません。[消費・返却ルール](free-beta-credit-failure-rules.md)に従い確認します。

### 観戦・結果の共有とプライバシー

- 一般公開後は観戦URLからほかの人を招く体験を想定します。ただし、公開前の検証URL・Basic認証などの資格情報は配布しないでください。
- プレイヤー名・スコア・ゲーム画面等は、観戦・ランキング・結果共有を通じてほかの利用者に見える場合があります。実名や連絡先を表示名に使わないでください。
- 結果URLは結果の共有であり、プレイ動画のリプレイではありません。未反映のゲーム別OGP画像等を利用可能として予告しません。
- アクセス解析は同意した場合のみ有効になり、拒否してもプレイ・観戦できます。

## 感想・不具合を送る

| 導線 | 使い方 |
| --- | --- |
| 常設リンク | ページ最下部の「感想・不具合を送る」。ゲームをしていなくても利用できます |
| プレイ結果 | 3ゲームの最終結果画面の「感想・不具合を送る」。ランキング登録・リトライ等とは別の任意の補助リンクです |
| 控えめな自動案内 | プレイ終了後、または進行中の観戦を累計60秒以上見た後にゲーム一覧へ戻ったとき。プレイ中・観戦中には自動で開きません |

自動案内はブラウザごとに日本時間で1日1回まで。送信成功後は7日間控えます。同じ滞在で手動フォームを開いた場合等も重複案内を控えるため、毎回表示されなくても手動リンクは利用できます。

- ログインやメールアドレスは不要です。種別「よかった」「気になった」「不具合」と、1〜2,000文字の本文を送れます。回答や登録をプレイ条件にせず、報酬クレジットもありません。
- ゲーム名・プレイ／観戦／サイト利用の区分、送信時の表示名、PC／スマホ・ブラウザ種別、日時が一緒に記録されます。筐体IDやURL、詳細な端末情報は自動収集しません。
- 本文は非公開で運営者だけが閲覧し、90日を過ぎた投稿は定期削除の対象になります。
- フォームには返信機能がありません。返信や削除相談が必要な場合は [X @pulbase](https://x.com/pulbase) のDMへ。できる限り早く対応しますが、返信までお時間をいただく場合があります。
- 送信失敗時は再読込せず表示を確認してください。同じページのフォームには本文が残り、再送できます。再読込後まで本文を保存する機能はありません。

### 安全な報告例

分かる範囲だけで十分です。短い感想だけでも構いません。

```text
11/2 20:10ごろ（日本時間）、DOT WAVEをiPhone Safariで観戦しました。
終了後に下へスクロールすると、ボタンの一部が見切れました。
一度だけで、再読み込み後は表示されました。
```

不具合の場合は、発生日時、ゲーム名、プレイ／観戦、端末・ブラウザ、直前の操作、期待と実際の違い、画面のエラー文言を任意で添えてください。残高の問題だけは開始前後の表示枚数も役立ちます。

パスワード、Cookie、トークン、メールアドレス、決済情報、生の開発者ログは送らないでください。画面写真が必要なら、フォームでは画像を添付できないため別の受付方法を運営者と確認し、不要な個人情報を隠してください。スクリーンショットの提出を必須にしません。

残高不整合・他人の情報の表示など重大な問題では、何度も開始し直さず利用を止め、秘密情報を含めずX窓口へ連絡してください。運営者は報告を公開Issueへそのまま転載せず、匿名化して必要な情報だけを記録します。

## 障害のお知らせ

状況に応じて停止・再開を判断し、可能な限り迅速に対応します。障害・復旧のお知らせは [X @pulbase](https://x.com/pulbase) でご案内します。対応時間や復旧期限を保証するものではありません。
