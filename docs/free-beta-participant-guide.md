# 無料ベータの参加案内・不具合報告手順（下書き）

更新日：2026-10-25 / Issue #36

この資料は招待準備用。参加募集・招待の送信・本番公開の承認ではない。CI/CD見直し中のためデプロイせず、以下の未確定事項が決まるまで招待文を送信しない。

## 招待前に運営者が確定すること

| 項目 | 現時点の扱い | 招待開始の条件 |
| --- | --- | --- |
| 対象と規模 | 国内18歳以上、最初5名、確認後に合計10名までの既存案 | 対象者と参加意思を確認。人数を自動で増やさない |
| 招待経路 | 知人への個別DMを提案、運営者確認待ち | 送信先・経路を確定。公開SNSで募集しない |
| 参加URLとアクセス境界 | 未確定 | 招待者に渡せる専用経路を確認。検証用Basic認証・管理用資格情報は配布しない |
| 開始日時と対応時間帯 | 未確定 | 日本時間の具体的な日時・曜日・担当を決める。24時間即応を約束しない |
| 問い合わせ | Xの `@pulbase` | 個別連絡を受け取れる経路を実際に確認。公開投稿で個人情報を求めない |
| 公開するゲームと端末 | PCソロ、PC/スマホ観戦を基本とする範囲案 | ゲーム/OS/ブラウザ別の確認結果を見て最終決定。未確認端末は試験協力扱いとする |
| 公開候補 | 未確定 | 配信コードのリビジョン、必要な修正反映・再確認、公開判断を記録 |

同時6人程度は運用上の目安で、性能保証・実装された参加上限ではない。招待URLや観戦URLを知っていることだけを、参加者限定のアクセス制御とみなさない。長時間負荷試験は保留・未合格のまま。

## 参加者に伝える内容

### 何を楽しめるか

PULBASE（パルベース）は、本気のプレイを気軽に観戦し、自分でも挑戦できるオンラインのゲームセンターです。まずは観戦からでも参加できます。

- 対象候補はBUZZ BARRIER、DOT WAVE、深海サルベージ。初回ベータはソロプレイとライブ観戦に限定します。
- Googleでのユーザー登録は任意です。観戦・ゲストプレイのために登録を強制しません。
- 対戦・協力、チャット、リプレイ、有料クレジット購入は今回の提供対象ではありません。
- スマートフォンでは観戦を優先します。スマホのプレイや、未確認の端末・ブラウザの動作を保証する案内はしません。
- 観戦映像はライブです。終了後に見返すリプレイ機能はまだありません。

### 無料クレジット

| 内容 | 現在の仕様 |
| --- | --- |
| 最初のプレイ特典 | 受取画面で無料5枚を受け取れます。サイトを見るだけ・観戦するだけでは受取不要です |
| 初回のユーザー登録特典 | 登録すると追加5枚。初回特典と合わせて10枚。繰り返し登録等で何度も付与されるものではありません |
| 毎日の補充 | 日本時間の1日1回、利用時に残高が3枚未満なら3枚になるまで補充。3枚ずつ無制限に加算するものではありません |
| 1プレイ | 開始時に1枚を使用。終了後の新しい挑戦にも1枚必要です |
| 観戦 | クレジット不要です |
| 購入 | 無料ベータ中は購入できません |

ゲストはブラウザの保存情報に依存します。Cookie/サイトデータ削除やプライベートブラウズ終了で同じゲストに戻れなくなることがあるため、残高を保存したい場合はユーザー登録を検討してください。登録は端末間の残高共有とランキング名設定にも利用できます。

開始前キャンセルと、開始後の離脱・不具合では返却の扱いが異なります。「不具合なら必ず自動返却」とは案内しません。[消費・返却ルール](free-beta-credit-failure-rules.md)に基づき運営側で確認します。

### 共有とプライバシー

- ベータ中の観戦URLは、案内された招待範囲を超えて共有しないでください。共有ボタンが存在しても、一般公開の許可を意味しません。
- プレイヤー名・スコア・ゲーム画面は観戦やランキング等で他の利用者に見える場合があります。公開したくない実名や連絡先を名前に使わないでください。
- 結果共有URLは記録の共有であり、プレイ動画のリプレイではありません。
- アクセス解析は拒否してもプレイ・観戦できます。問い合わせにパスワード・Cookie・ログイントークンを添付しないでください。

## 不具合が起きたら

1. 連打や何度もの開始・再読み込みをせず、発生時刻と画面の状態を控えてください。
2. 下のテンプレートを使い、運営者が案内した個別連絡先へ送ってください。残高不整合や他人の情報が見えた場合は利用を止め、その旨を優先して連絡してください。
3. スクリーンショットは、通知・メールアドレス・他人の名前など不要な情報を隠してください。秘密情報や個人情報が写る場合は画像を送らず、まず文章だけで連絡してください。
4. 運営側が受領・調査します。返信時間や復旧時刻を確約するものではありません。

```text
発生日時（日本時間）：
ゲーム名：
プレイ中 / 観戦中：
端末・OS・ブラウザ（分かる範囲で）：
直前に行った操作：
期待した動き：
実際の動き・画面のエラー文言：
毎回起きる / 一度だけ / 未確認：
クレジットに関係する場合のみ、開始前後の表示残高：
スクリーンショット（任意・不要な個人情報は隠す）：
```

筐体の特定が必要なら、運営者から追加確認します。Cookie、認証ヘッダー、Basic認証のユーザー名/パスワード、決済情報、生の開発者ログは求めません。公開Issueに利用者の報告をそのまま転載せず、再現に必要な情報だけ匿名化して記録します。

## 個別招待文の下書き（未送信）

以下は上記の未確定事項を解消してから使う文章です。角括弧の項目を残したまま送らないでください。

> PULBASE（パルベース）の無料ベータにご協力いただけませんか？
> ゲームのライブ観戦と、自分で挑戦する体験を試せるオンラインのゲームセンターです。
> まずは少人数で、PCでのソロプレイ・PC/スマホでの観戦を確認します。ユーザー登録は任意で、料金の支払いはありません。
> 初回は無料5クレジット、初めてのユーザー登録で追加5枚。毎日、残高が3枚未満の場合は3枚まで補充されます。
> 参加条件は日本国内・18歳以上です。テスト中のため不具合や停止の可能性があります。
> 参加先：[確定した参加URL]
> 試用のお願い：[確定した日時・日本時間]
> 対応可能な時間：[確定した曜日・時間帯]
> 問い合わせ：[確認済みの個別連絡先]
> 今回は招待者限定です。参加URL・観戦URLは、案内した範囲を超えて公開しないようお願いします。

## 運営側の受領・振り返り

- 受領記録は日時、対象ゲーム・端末、影響、再現状況、暫定対応、次の連絡を必要最小限で残す。残高の調査・補正は既存の運営手順に従い、台帳の直接加算を即答しない。
- 重大な残高・情報漏えい疑い、開始不能が続く場合は増員を止め、公開停止等の判断を運営者へ確認する。この資料だけで設定・残高・公開状態を変更しない。
- 最初5名の主要導線・問い合わせ対応を振り返り、未解決事項を確認してから合計10名への拡大を判断する。7日後の振り返りや人数到達だけで自動拡大しない。
