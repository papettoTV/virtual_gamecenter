# PULBASE 無料ベータ規約と情報取扱いの公開前確認

更新日：2026-10-12

無料ベータの実装に合わせてサイトの利用規約・プライバシーポリシーを改訂した。これは法的適合性の確定や一般公開の承認ではない。以下の運営設定と未決事項を確認してから公開する。

## 確定事項と反映先

| 項目 | 内容・実装との対応 |
| --- | --- |
| 運営者表示 | ユーザー指定のpapettoTV。法令上の氏名・名称・住所等の必要表示とは分けて確認 |
| 問い合わせ | ユーザー指定のX @papettoTVへのDM。規約・ポリシーと全体フッターからプロフィールへリンク |
| 利用規約 | `apps/web/public/legal/terms.html`：無料配布・消費・購入停止、ゲスト/登録、公開観戦、ランキング/共有、禁止行為、権利、変更/停止、責任 |
| プライバシー | `apps/web/public/legal/privacy.html`：実際の取得項目・目的、公開範囲、Cookie/端末内保存、外部送信、保存・削除の現状 |
| 版管理 | 本文とWorkerの同意版を2026-10-12.3へ更新。旧版同意は新しい登録手続の同意としては扱わない。退会の再認証では新しい規約同意を強制しない |
| GAの任意同意 | 同意前/拒否時はタグ非読込。180日保存・撤回・設定再表示を実装。プレイ/観戦/特典とは独立。本番の拡張計測無効化・送信実測と法務判断は未完了。詳細は [解析同意設計](analytics-consent.md) |
| 同意導線 | トップ・観戦・プレイ開始では同意画面を強制しない。登録時に確認。同意更新だけでクレジットを付与しない |
| 無料クレジット | 初回受取り5枚、初回登録5枚、日本時間で1日1回、3枚未満なら3枚まで補充。仮確保分・既存購入分を含む未消費残高で判定 |
| 購入 | 新規購入はUI/APIで停止。過去の残高・取引の確認/付与は維持 |
| Google | `openid profile email`を要求し、識別子・名前・画像URL・メールを保存。パスワードは取得しない |
| 公開情報 | 筐体のライブは公開。ランキングは任意登録。結果共有は記録時点の名前・成績等を公開する静的結果で、リプレイではない |
| 残高/ログアウト | 残高はサーバー台帳。Cookie削除・ログアウトはサーバーの個人情報削除ではない。既存アカウントへのログイン時に別ゲスト残高の自動合算はしない |

## 公開前に解消する事項

- [ ] **運営者の必要表示**：papettoTVは表示名。本名/正式名称・住所等の保有個人データに関する公表事項を確認し、必要な情報を掲載する。法令上の必要情報をハンドル名だけで代替したと判断しない。
- [ ] **X窓口**：未フォロー・未登録者が連絡できるか、DM受信設定を確認する。Xを利用できない人の請求・問い合わせ手段も確保する。受付の確認方法、担当者、対応目安、本人確認、アカウント凍結時の代替連絡手段を決める。
- [x] **アプリ内の保存・削除方針**：`docs/data-retention-and-deletion.md`で確定。所有者・特典資格を分離し、退会・ゲスト削除・公開記録削除・受付確認・期限処理を実装。バックアップ復元時の独立R2証跡からの再削除を自動テストで確認。
- [ ] **本番の保存・削除運用**：D1移行、非公開R2、Cronと失敗通知、Time Travel復元のリハーサルを確認する。Cloudflare/GAのログ保持設定、Xの問い合わせ記録・手動削除、購入関連の個別対応、年次レビュー、調査時の例外保持は運営作業として検証する。
- [x] **GAのアプリ内制御**：登録同意と独立した任意の解析同意・拒否/停止・撤回を実装。同意までタグを読み込まない。ローカル動作と自動テストを実施。本番公開はまだ行っていない。
- [ ] **GAの本番確認と法務判断**：管理画面で拡張計測を無効化し、送信最小化が実測でも機能することを確認する。手動page_viewは個別ID・クエリ・ハッシュを除去、参照元を空欄・タイトルを固定化。管理画面の保持期間・データ共有・広告設定、利用条件・外部送信規律・国内外の適用法令の確認は未完了。
- [ ] **国外処理・委託**：Cloudflare/Google/X/Meta/Stripeの契約主体、処理国、委託・第三者提供の整理、保護措置、必要な本人向け情報提供を確認する。「海外で処理する場合あり」と記載するだけで外国第三者提供の手続が完了したと判断しない。
- [ ] **公開データ**：プロフィール画像・名前の実際の各画面への表示、過去共有名の固定、SNSプレビューのキャッシュ、削除要求時の限界を検証する。ゲーム別の共有成績項目の追加時は本文の範囲内か再確認する。
- [ ] **無料特典の運用**：Cookie消失時の限界、乱用調査・利用制限、障害や切断時の調査/補正、未成年利用への対応手順を決める。
- [ ] **適用日とレビュー**：専門家等にサービス構成と本文を提示し、未確定事項の解消後に最終版・適用日・周知方法・必要な再同意を確定する。文言だけで「ベータなので一切責任を負わない」としない。

有料販売・決済条件の整備は今回再開しない。ただし、既存の購入残高や成立済みの取引に関する対応を放置してよいという意味ではない。
