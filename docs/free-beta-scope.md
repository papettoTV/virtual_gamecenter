# 無料ベータ範囲案

更新日：2026-11-02 / Issue #36

## 最新方針

2026-10-30以降の運営者方針に合わせ、知人5名の確保や招待5→10名の段階を公開条件にせず、一般公開ベータを想定して準備する。流入規模の議論よりフィードバックのしやすさを優先する。ただし、本番公開の実施・アクセス制限解除・SNS告知は別途承認が必要。

- BUZZ BARRIER、DOT WAVE、深海サルベージのソロプレイとライブ観戦が対象。対戦・協力・チャット・リプレイは初回提供対象外。
- 観戦・ゲストプレイはログイン不要。Google登録は任意。新規購入は停止する。
- 初回受取5枚・初回登録5枚を維持。無料付与履歴のある利用者は日本時間の日付ごとに1回、残高3枚未満なら3枚まで不足分を補充。未訪問日の分は蓄積しない。
- フィードバックは常設リンク、最終結果リンク、プレイ終了／一定時間の観戦後に一覧へ戻った際の控えめな自動案内から任意に送れる。返信機能はない。
- Mac / Chromeのソロ・観戦とiPhone / Safariの観戦の既存証跡を基準に、公開候補版で再確認する。Windows・Android等は実機未確認、スマホプレイは試験対応として案内する提案で、対応範囲の確定は運営者判断。
- 過去の国内18歳以上案を一般公開でも採用するか、対応端末、問い合わせ受付・対応時間、公開日時、停止時の告知・再開判断を確定する。

判断項目と告知下書きは[参加案内・不具合報告手順](free-beta-participant-guide.md)のB-01〜05へ集約する。同時6人は過去の運用目安であり、性能保証・強制上限・一般公開の定員として扱わない。人数上限や待機列をこの資料だけで新設しない。

## 公開判定

BT-01/02/03は対応中。[公開前チェックリスト](production-launch-checklist.md)の未確認事項、素材権利・本番設定等の公開前条件と、保留・未合格の長時間負荷試験を区別する。一般公開を小さく告知する方針は、障害リスクの受容や公開可否の確定ではない。

この資料更新では本番・main・Cloudflare設定・アクセス制限・負荷試験・告知送信を変更／実施しない。
