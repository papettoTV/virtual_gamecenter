# 通常運用の自動実装・レビュー・検証公開

- `実装:自動` ラベル付きIssueだけを自動実装の対象とし、GitHub Actions上のCodexが実装・PR作成を担当する。ラベルなしのIssueはチャットから手元実装する。Issue・PRのタイトルと本文は日本語で記述する。
- 必須CIと独立Codexレビューに合格したPRを`develop`へ自動マージする。その実マージSHAのCI成功後、人がstaging承認を1回行う。
- 検証公開とHTTP／ブラウザ回帰は各1回行う。失敗時は修正PRで対応する。`main`への反映・本番公開には、別途人の判断が必要となる。

この文書は運用手順を示すものであり、実行結果の成功を報告するものではない。
