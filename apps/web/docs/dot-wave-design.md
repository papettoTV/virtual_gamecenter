# DOT WAVE — ドットの電光アリーナ

採用イメージ：`concepts/rhythm-battle/dot-wave.png`。
入口 `/labs/dot-wave`。旧 `/labs/mochi-duel` も互換入口として残す。

## 表現

- 黒紫の背景に、シアン #13e5f3・ピンク #ff39bc・ライム #baff39。
- キャラクター、音符、中央コア、スピーカー、床を隙間のある四角いドットで描く。
- ロゴは専用の5×7文字パターン。開始前の説明と操作名は残し、プレイ中の状況説明・NEXT / NOW・SYNC / GOOD / MISSは画面に出さず、読み上げ用の説明として残す。
- ドット絵は `DotScene.tsx` のSVG矩形として描画。画像生成したコンセプト絵を画面に貼り付けず、ゲーム状態に反応するパーツとして実装。
- 成功時はキャラクターのジャンプときらめき（良い判定ほど大きい）、音符パルス、ガード時の粒の散開。ミス・入力抜けは灰色のしょんぼりしたキャラと、崩れ落ちる音符・低い音で伝える。
- HPは数値とバー、太陽は音符コア。難易度を数値表示せず、コアの放射状の光が伸びる。勝負終了はFINAL WAVE / KNOCKOUT。
- 専用アイコン `public/assets/dot-wave-icon.svg`、ブラウザタイトルもDOT WAVEへ変更。
- 人が操作するキャラの上に「押す手＋下向き矢印」。次の番は約1秒周期で点滅し、今の番は点灯。操作ボタンにも同じ手を表示する。動きを減らす設定では点滅を控える。
- CPU側には番の枠や手の合図を表示しない。CPUの準備・攻撃・防御中はリズムバーを囲むピンクの枠も表示しない。同端末2人対戦では両方の人に合図を出す。
- 攻撃力アップの緑の丸とCHARGED文字を廃止。キャラの横に点滅しない金色の音符と上向き矢印を置き、強化中に飛ぶ音符も金色・大きめにする。
- 相手の番の入力は黄色の「待って」の手・キャラとボタンの短い揺れ・小さな二音で案内。警告は約0.75秒、または自分の入力受付開始で消し、追加の減点はしない。マウス・タッチ・キー共通で、直前入力の許容幅は維持する。
- ダメージや拍などの数字は残す。攻撃／防御は音符／シールドのアイコンで表す。
- 自分の攻撃前は音符＋4・3・2・1、相手の攻撃中は自分の防御に向けてシールド＋4・3・2・1を表示。CPU用のカウントダウンは出さない。同端末2人対戦では次に操作する側の色で予告する。

## 音

`audio.ts` のWeb Audio合成。追加音源・外部フォント・外部サービスへの依存なし。

- 方形波の短いパルスをお手本・タップ音に使用。
- 三角波の低音で拍を支える。
- SYNCは高音を重ね、GOODは単音、MISSは低い下降音。
- 防御は攻撃より高い音域。完全防御・難易度上昇は上昇アルペジオ。
- 被弾は短い低音、勝利は上昇音、敗北は下降音、引き分けは往復音。
- 全て共通の音量ゲインを通る。一時停止はAudioContextごと停止し、終了時に演奏を止めて結果音を再生。

## 維持するルール

自動ランダムパターン、4攻防ごとの難易度上昇、準備4拍→攻撃4拍→防御4拍の連続進行、CPU戦の2種類の終了方式を維持する。通信対戦はレベル1からFINAL WAVE方式で開始する。
ソロの「もちつきビート」は別ゲームとして残し、ゲーム一覧と筐体内のリンクからDOT WAVEへ案内する。通信対戦では自分側だけに合図を出し、観戦画面には操作ボタンを出さない。


## CPUの3ステージ構成

- 1st STAGE / PULSE：整数拍のタップのみ。長押し・8分音符なし。
- 2nd STAGE / IRON BEAT：角と装甲のある中ボス。整数拍で始まり終わる長押しを追加。
- 3rd STAGE / NOVA：翼のあるラスボス。長押しに加えて8分音符を追加。CPUコースでは16分音符は使わない。
- PULSE・IRON BEATは最大10ターン、NOVAは最大20ターン（体力が尽きた場合はその時点で終了）。勝利後にNEXTを押すと説明画面を挟まず3カウントダウンから次ステージを開始し、体力・攻防数・テンポ・盛り上がりをリセットする。3rd勝利で全ステージクリア。
- 敗北・引き分けでコース終了。再挑戦は1stから。1クレジットで3ステージを通して遊び、途中の勝利ではソロ終了を送信しない。
- 通信対戦・同じ端末の2人対戦のリズム抽選は従来どおり。CPUのステージ番号は観戦スナップショットに含め、キャラクターと音声時計も次ステージに同期する。

## CPUコースのスコア（初期版）

- 3ステージ通算。自分のぴったり100点、おしい50点。長押しは開始・終了とも成功したときに100点／1コンボを終了時に加算する。
- 今回の成功を含むコンボ数で、3コンボごとに倍率を0.1加算。30コンボから×2.0固定。失敗・押し忘れ・余分なタップで切れ、相手の番の誤操作は注意のみ。攻守交代・ステージ間は継続。
- ボス勝利時に残り体力×5点を加算し、倍率は適用しない。
- プレイ中は通算スコアを常時表示。コンボは成功時にリズム欄の上段中央にある大きい音符・シールドマークの右横へ約0.35秒だけ表示し、少し上昇しながら消える。結果では最大コンボ・体力ボーナス累計・自己ベストも表示。自己ベストはこのブラウザ内で決着方式別に保存。観戦はプレイヤーのスコアを共有し、観戦者の自己ベストには記録しない。
- 再挑戦はスコア・コンボともリセット。人間同士の対戦へのスコア導入と公平なランキングは今後の検討対象。

## 表示の増減による位置ずれの抑制

- 手番アイコンを中央に固定。カウントダウンとコンボは右横への重ね表示とし、文字の出入りでアイコンを移動させない。
- プレイ領域の寸法を各画面で共有し、開始説明・一時停止・結果は領域内へ重ねて表示する。長い説明・結果は内部でスクロールする。
- 申込通知は操作ボタンの上への重ね表示。承諾画面は一時停止・結果領域内へ重ねて表示し、既存のボタンを押し下げない。
- 筐体の操作欄と再挑戦のボタン幅を固定し、待機文言やボタンの出入りによる移動を抑える。連勝の王冠も固定し、数字は右横へ配置する。
- モード表示は1行、結果のスコアは固定の列配置。文字数・桁数による意図しない折り返しを抑える。

## ALL CLEARのランキング登録

- ALL CLEAR画面では撃破説明・双方の体力・与えた／受けたダメージを表示せず、成績と操作を中心にする。
- 自分がCPUコースの3ステージをクリアした場合にランキング登録ボタンを表示。既存のランキングAPIを使い、現在のプレイヤー名で通算スコアを登録する。観戦者は登録できない。
- スコア規則の識別子は `dot-wave-score-1`。同じ規則の上位10件を登録後に表示し、登録中・登録済みはボタンを無効化する。通信失敗時は再試行可能。
- 登録するプレイ時間は完了した攻防の合計時間とし、ステージ間の待機・一時停止・開始前のカウントダウンを含めない。
