# 自機の無敵・レベルアップ演出

基準は「宣伝素材」のPR動画v17で収録したCanvas描画。収録元のコミットは `12a584f`、素材と撮影条件は `deliverables/pulbase-C-hyperframes/cut-bgm/media-v17/provenance.json` に記録されている。

- 無敵シールドは中心から外側へアルファ0.46 → 0.28（半径48%）→ 0.12の青緑グラデーション。残り0.5秒で透明点滅する。
- レベルアップ直後の0.42秒は、7区間で折れ曲がる太い稲妻10本を白・機体色で交互に描く。周囲の発光、拡大する白い円、白いリングも含める。
- 描画順はシールド → レベルアップ演出 → 自機 → 中心マーカー。稲妻を常時表示したり、無敵時間・当たり判定を変更したりしない。

`rendering/player-effects.ts` がCanvasとThree.jsの共通描画元。Three.jsのシールドは共通関数から作る静的テクスチャ、レベルアップは26フレームの事前描画アトラスを使う。プレイ中はUVと回転のみ更新し、毎フレームのCanvasぼかし処理やテクスチャ再アップロードを避ける。ランダムな稲妻の形そのものは毎回の収録フレームと完全一致するわけではないが、折れ数・本数・太さ・発光・リング・透明度は同じ定義を使用する。

自機の色を変更した場合はアトラスを作り直して前のテクスチャを解放する。ゲーム終了時もシールド・アトラス・ジオメトリ・マテリアルを解放する。

## かすりの火花と擦過音

かすり時だけ、弾に近い自機の側から白〜薄い橙色の線状火花を5本飛ばす。長さ8〜16、寿命0.12〜0.26秒。速度方向に尾を引き、消える前に短く薄くなる。通常の被弾・爆発の丸いパーティクルや、レベルアップの稲妻は変更しない。全パーティクル数の上限を共用し、Three.jsでは細い帯をまとめて1回で描画して、スマホでも縮尺に合う線幅を保つ。Canvas版でも線として描く。

かすり音は音程のある電子音ではなく、バンドパスフィルタを通した約60msのノイズによる短い「カスッ」という擦過音。ノイズのバッファを再利用し、30ms未満で重なるかすり音は省略して密集弾での音量・ノード数の増加を抑える。コンボによってわずかに音量は変わるが音程は上げない。
