# 自機の無敵・レベルアップ演出

基準は「宣伝素材」のPR動画v17で収録したCanvas描画。収録元のコミットは `12a584f`、素材と撮影条件は `deliverables/pulbase-C-hyperframes/cut-bgm/media-v17/provenance.json` に記録されている。

- 無敵シールドは中心から外側へアルファ0.46 → 0.28（半径48%）→ 0.12の青緑グラデーション。残り0.5秒で透明点滅する。
- レベルアップ直後の0.42秒は、7区間で折れ曲がる太い稲妻10本を白・機体色で交互に描く。周囲の発光、拡大する白い円、白いリングも含める。
- 描画順はシールド → レベルアップ演出 → 自機 → 中心マーカー。稲妻を常時表示したり、無敵時間・当たり判定を変更したりしない。

`rendering/player-effects.ts` がCanvasとThree.jsの共通描画元。Three.jsのシールドは共通関数から作る静的テクスチャ、レベルアップは26フレームの事前描画アトラスを使う。プレイ中はUVと回転のみ更新し、毎フレームのCanvasぼかし処理やテクスチャ再アップロードを避ける。ランダムな稲妻の形そのものは毎回の収録フレームと完全一致するわけではないが、折れ数・本数・太さ・発光・リング・透明度は同じ定義を使用する。

自機の色を変更した場合はアトラスを作り直して前のテクスチャを解放する。ゲーム終了時もシールド・アトラス・ジオメトリ・マテリアルを解放する。

## かすりの火花と擦過音

かすり時だけ、弾に近い自機の側から白・シアン・薄紫の線状火花を12本、放射状に飛ばす。参考画像に合わせ、長さ24〜48、幅2ゲーム座標、寿命0.32〜0.5秒、初速320〜520ゲーム座標/秒に拡大。速度方向に尾を引き、消える前に短く薄くなる。通常の被弾・爆発の丸いパーティクルや、レベルアップの稲妻は変更しない。全パーティクル数の上限180を共用し、Three.jsでは細い帯をまとめて1回で描画して、スマホでも縮尺に合う線幅を保つ。Canvas版でも同じ幅の線として描く。

かすり音のみ再生ゲインを1から0.4（約−8dB）に下げる。他の効果音の音量やU3の音色は変更しない。

かすり音は試聴案U3（Uの反射・ディレイを外し、ビーム周波数と水音の帯域を1.5倍にした音）を採用。`deliverables/buzz-graze-audio-options/round6/samples/05-bright.wav` の最初の単発を0.15〜0.55秒で切り出し、`src/games/graze-duel/assets/graze-u3.wav` として使う。波成分は約0.28秒、素材は余韻を含め0.4秒。再生時に追加の音程変更はしない。`node scripts/extract-graze-sound.mjs u3` で再生成・検証できる。以前のJとUも引数 `j` / `u` で再生成できる。

試聴音に別の高音を足したり、コンボでピッチを変えたりしない。素材の読み込み・デコード結果を再利用し、毎回のフィルタ合成は行わない。30ms未満の連続発音を省略し、同時再生と読み込み待ちを合わせて最大8音に制限する。終了した音のノードを解放し、ゲーム終了後に読み込みが完了しても再生しない。

参考として指定された動画は `https://www.youtube.com/watch?v=X4kdQ4osliQ`（サイヴァリア リビジョン）。ページは確認したが音声を直接聴き比べられていない。動画から音声素材は取り込まず、独自合成した候補を試聴してもらい、Jを選択した。
