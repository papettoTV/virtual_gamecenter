# BUZZ BARRIER ボス戦設計

## 目的

通常戦の「弾をかすって攻撃を送り合う」遊びから、ボス戦では「ボスの攻撃を読み、かすって無敵シールドを作り、接近して攻撃する」遊びへ切り替える。

## 基本サイクル

### 登場

1. 出現条件を満たした時点で、新しい通常弾と対戦攻撃弾を停止する
2. 画面内に残っている弾は消さず、そのまま移動させる
3. 短い待機時間の後、ボスが影から現れる演出を開始する
4. 約5秒かけて姿を見せ、自機のレベルアップ無敵が残っている場合は完了直前で待機する
5. 無敵終了後にボスの当たり判定、HP表示、攻撃を有効にする

### 戦闘

1. 規則的な弾幕を発射する
2. プレイヤーが回避・かすりを行う
3. 発射済みの弾は画面外へ出るまで残す
4. 短い休止を入れる
5. 次の攻撃へ切り替える

ボス出現中は通常弾と対戦相手からの攻撃弾を停止し、ボス攻略だけに集中できる状態にする。

## シールド攻撃

- レベルアップ1回につき、ボスへ攻撃できる権利を1回得る
- 同じ無敵シールドでボスに接触し続けても、レベルアップ回数を超えるダメージは与えない
- 連続レベルアップした場合は攻撃権を蓄積し、ボスへ接触中に連続攻撃できる
- 無敵シールドが終了した時点で、未使用の攻撃権は失う
- ボス1は12回、中ボスは20回、ラスボスは28回の攻撃で撃破する

## 攻撃パターンの原則

- 完全なランダム攻撃は使わず、見て理解できる規則を持たせる
- 画面内には必ず回避経路を残す
- 安全地帯を固定せず、攻撃ごとに移動を要求する
- 弾の間隔には、回避だけでなく意図的にかすれる余地を残す
- 弾数だけで難しくせず、速度・角度・攻撃間隔の組み合わせで調整する
- 複数パターンを同時に重ねる場合は、単体で攻略可能なことを確認してから行う

## 初期攻撃パターン

### 扇状弾

ボスから下方向へ広がる扇状弾。攻撃範囲の境界を予告し、弾と弾の間を抜ける基礎を教える。

### 狙い撃ち連射

攻撃開始時のプレイヤー位置を固定して狙う連射弾。発射方向を見て位置をずらす回避を教える。

### 中央封鎖

中央を回避困難な高密度弾で封鎖し、プレイヤーを左右端へ移動させる。左右端には密度を抑えた紫弾列を流し、回避しながら意図的にかすって無敵を作れる構成にする。

### ボーナス弾幕

各ボスの初回被弾後に一度だけ発生する。プレイヤーの近くへ直線状の弾を高密度で流し、最初の弾をかすると連続してゲージを獲得できる構成にする。連続レベルアップで攻撃権を蓄積し、そのままボスへ接近して連続攻撃できる報酬区間として扱う。

## 見た目の原則

- ボス1はシンプルな重迎撃機、中ボスは逆三角のステルス飛行艇、ラスボスは多翼の巨大空中要塞とする
- 全機とも真上から見た機首が下向きのデザイン。暗い装甲、赤い表示灯、暖色のエンジン噴射で敵陣営を統一する
- 機体の大きさと構造の密度で、後続ボスほど重厚さを増す。旧デザインの目・円形オーラ・ラスボスの回転は使わない
- 承認済み画像から生成した透過PNGをThree.jsとCanvasで共用し、翼がプレイエリアを出た部分は描画しない
- 登場時は約5秒かけて暗い状態から明るくなり、被弾時は機体が明るく光る
- シールド攻撃の判定は従来のボス中心と半径を使い、翼の張り出しに合わせた判定拡張はしない

素材は `public/assets/buzz-barrier/bosses/`。生成元・生成指示は同ディレクトリの `provenance.json` に保存する。

### ローカルでの外観確認

開発サーバーの `/cabinets/boss-art-preview?game=graze-duel&promoCapture=1&promoBoss=1` で、実際のゲーム進行・弾幕・描画を使った自動操作の撮影モードを開く。`promoBoss=2` は中ボス、`promoBoss=3` はラスボス。`renderer=canvas` を追加するとCanvas版を確認できる。撮影モードは開発ビルドだけで有効で、通常プレイの出現条件は変えない。

## 新しい攻撃を追加するときの確認

- 初見でも攻撃方向を予測できるか
- 回避経路が視認できるか
- 危険を取ってかすれる場所があるか
- 無敵シールドで接近する機会を作れるか
- 前後の攻撃と役割が重複していないか
- PCとスマホの両方で弾幕が読めるか
