# BUZZ BARRIERの移動・タッチ入力

- 人が操作する自機の速度倍率は0.85（従来0.75から約13%増加）。通常216.75、Shift低速131.75ゲーム座標/秒。CPUは従来の0.75を維持し、敵弾の速度は変更しない。
- Touch Events対応端末では、passive:falseのtouchstart/touchmoveで指の位置を直接読み取り、Pointer Eventsとの重複処理を避ける。非対応端末・マウス・ペンはPointer Eventsで操作できる。
- 最初に触れた位置をスティックの中心とし、移動イベントを受けた直後のゲーム更新から方向を反映する。待機タイマー・デッドゾーン・入力の平滑化は追加しない。単にタップしている間は方向が未指定なので移動しない。
- 最初の指だけを追跡し、別の指や別pointerIdからの移動・終了イベントで操作を変えない。終了・キャンセル・ポインターキャプチャ喪失・ゲーム破棄時には入力を解除する。
- 観戦中はスクロールを阻害しない。READY中やモーダル表示中の開始入力は受け付けない。

コード内に元から移動開始を遅らせるタイマーはない。今回はブラウザのpointermove通知待ちを減らす変更であり、端末・ブラウザの通知間隔、リフレッシュ周期、処理負荷による遅延がゼロになる保証はない。実機で初動・方向転換・指を離した際の停止を確認する。
