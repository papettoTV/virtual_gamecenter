# BUZZ BARRIERの一時停止画面

- 通常の一時停止はCanvas内の文字描画ではなく、HTMLの暗幕・説明・ボタンを使う。Three.js（z-index:1）より前面の7で描き、対戦承認（8）より下に置く。READY開始時は従来の開始・クレジット確認を維持する。
- 中央に主操作の「▶ 再開」、その下に控えめな「別のゲームをする」を配置。スマホの右上の▶もそのまま使え、説明も実際のアイコンに合わせる。PCではSpaceも使える。
- スマホ全画面の上部44pxは既存のステータス・一時停止アイコン用に空ける。縦・横の画面で操作説明とボタンをスクロールできる。
- 中央ボタンはrequest-buzz-resumeイベントを送り、ゲーム側で一時停止中・開始待ちでない・ゲーム終了でない・プレイヤーであることを確認して既存の再開処理を呼ぶ。多重押しで再び停止したり、READYでクレジット確認を飛ばしたりしない。
- 観戦者には再開待ちの説明だけを表示し、再開ボタンは出さない。ゲームの終了時はこのパネルを隠して結果画面を優先する。
- HTMLパネルがない独立Canvas描画では従来の停止表示を残す。
