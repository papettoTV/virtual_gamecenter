# DOT WAVE：リズム対戦試作

URL: `/labs/dot-wave`（旧 `/labs/mochi-duel` も同じ入口）。入場時に `/cabinets/{id}?game=dot-wave` を作成する。ゲーム一覧・もちつきビートの筐体説明からも起動できる。
CPU戦・観戦・承認制の通信対戦に対応。新規プレイ／挑戦は1クレジット。通信仕様は `dot-wave-online.md` を参照。ランキングは未対応。

## 進行

開始操作は最初の1回だけ。準備4拍 → 攻撃4拍 → 防御4拍を繰り返す。
各攻防の開始時、その段階に対応する3種類の候補から一様ランダムにリズムを決定する。技選択ボタンはない。
攻撃側はお手本の音に合わせて入力し、防御側は続く4拍で同じリズムを返す。
攻防の境界でダメージを確定し、音を止めずに次の準備へ進む。結果は準備中に表示する。
勝敗決定時だけ2.2秒の余韻の後に結果画面を表示。

## 難易度

4回の攻防（双方が2回ずつ攻撃）で1段階上がる。レベルやBPMの文字表示はせず、中央の音符コアの光の列の長さ・色・拍に合わせた点灯で表す。
段階が変わる攻防の先頭から新しいテンポを適用。先頭拍は既存の音声時計を引き継ぎ、拍の二重再生や待ち時間を挟まない。

|段階|BPM|リズム候補|
|---|---|---|
|1|108|PULSE、REST、ECHO|
|2|120|DOUBLE、BOUNCE、CHASE|
|3|132|DELAY、OFFBEAT、SPRING|
|4|144|TRIPLET、RUSH、SHIFT|
|5|156|OVERDRIVE、SONIC、SPARK|

現在の手作りパターンは15種類。KNOCKOUTまで続ける方式では6段階目以降も4攻防ごとに12 BPM上がり、5段階目の候補を使う。長期戦用の追加パターンは今後の調整対象。音符コアの光の列の描画サイズは画面内に収まる範囲に制限する。

## 終了方式の比較

開始前に切り替え可能。初期設定は「FINAL WAVEまで」。

- FINAL WAVEまで：5段階・20回の攻防まで。未決着なら残り耐久、同値なら引き分け。約111秒（終了演出を除く）。
- KNOCKOUTまで：攻防回数では終了しない。エネルギーが0になるまで続行。

エネルギーは100。どちらの方式でも先に0になった側が敗北する。両者が攻撃をすべて外し続ける場合、KNOCKOUTまで方式には終了条件が発生しない。

## 操作・判定

CPU戦・通信対戦とも各自の端末でスペース / F / タップ。通信対戦では元のプレイヤーがシアン、挑戦者がピンクを操作する。
スペースまたは開始ボタンでCPU戦を開始。Pまたはボタンで一時停止。CPU戦ではタブ非表示・フォーカスを失った場合も自動停止する。通信対戦は承認後に両者の準備が整うと共通の開始時刻で始まり、一時停止は無効。

- ぴったり：±min(60ms, 1拍の12%)、品質1。
- おしい：±min(150ms, 1拍の24%)、品質0.6。高速時も隣のノートと判定窓を重ねない。
- ミス：品質0。品質＝（ノート品質合計−余分な入力×0.35）÷ノート数、下限0。
- 威力＝四捨五入（（技威力＋反撃チャージ）×攻撃品質）。
- ダメージ＝四捨五入（威力×（1−防御品質））。
- 威力のある攻撃を全ノートぴったり・余分な入力なしで守ると次回攻撃に＋5。次の攻撃時に消費。自動反射ダメージはない。

攻撃側がミスしてもお手本の音は変わらない。CPUの成否は攻防開始前に抽選し、人間の入力を読んで変更しない。
難易度・勝負の長さ・CPUの強さは実際に遊んで調整する。
