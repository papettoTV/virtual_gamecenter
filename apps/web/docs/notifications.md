# 共通通知

通知は `features/notifications` に集約し、App直下のNotificationCenterで表示する。
成功・お知らせは表示開始から5秒後に消え、エラーは手動で閉じる。すべて×で閉じられる。
同じIDは置き換え、最大3件を表示する。4件目以降は待機し、表示されてからタイマーを開始する。

ゲーム固有の操作通知にはゲームIDをscopeとして指定し、退出時にclearScopeを呼ぶ。
再試行はactionへ渡す。通知を閉じても実行済みの決済・通信処理はキャンセルしない。
共有のコピー処理とランキング登録の結果通知は共通機能が担当し、ゲーム側では重複表示しない。
ランキング登録の再試行は元の登録ボタンから行い、成功後の画面更新も既存フローで処理する。

READY・ポーズ・勝敗・申込み承認・処理中表示は対象画面に残す。
購入完了は専用画面に表示する。決済確認の失敗時は同画面に再確認・閉じるボタンを表示する。
開発用地形エディタの操作ステータスはエディタ内に保持する。
