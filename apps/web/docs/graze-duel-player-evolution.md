# 自機の3段階進化

| レベル | 機体 |
| --- | --- |
| 0〜9 | 現行の矢じり型 |
| 10〜29 | 縦長コアと左右のブレード |
| 30以上 | 短い多角形コアと左右展開パーツ、細い中央尾 |

`rendering/player-ship.ts` の共通描画をCanvasとThree.jsの両方で使用する。観戦・対戦相手・CPUも、既存のプレイヤーレベルから同じ形を選ぶ。追加の通信項目は不要。

全段階の機体の描画範囲は従来と同じx=-17〜17、y=-18〜19（34×37）。中心座標、バンク表現、発光範囲、Three.jsの80×80表示面と320×320テクスチャの設定は変更しない。当たり判定、かすり判定、移動速度、シールド・稲妻・中心マーカーも従来どおり。

Three.jsは色または進化段階が変わったときだけ機体テクスチャを更新し、以前のテクスチャを解放する。同じ段階内のレベルアップや通常フレームでは再生成しない。リスタートなどでレベルが戻ったときも、そのレベルに応じた形へ戻る。
