# 自機の3段階進化

| レベル | 機体 |
| --- | --- |
| 0〜9 | 現行の矢じり型 |
| 10〜29 | 縦長コアと左右のブレード |
| 30以上 | 短い多角形コアと前方を囲む左右の盾形ウイング、後方へ広がるスカート形の本体後部 |

`rendering/player-ship.ts` の共通描画をCanvasとThree.jsの両方で使用する。観戦・対戦相手・CPUも、既存のプレイヤーレベルから同じ形を選ぶ。追加の通信項目は不要。

第3段階は第2段階の後方へ伸びるブレードと区別し、翼を機体中心より前方に配置する。盾形ウイングは外観のみで、弾を防ぐ判定や無敵効果を追加しない。

第3段階の翼は、厚い曲面の2パーツとする。それぞれの円弧を120度に抑え、翼同士の間に60度ずつの隙間を設ける。`rendering/player-wing-geometry.ts` の同一立体形状をThree.jsメッシュとCanvas投影で共用する。板の横幅を縮める方式ではなく、奥行きのあるパーツが機体の前後方向を軸に2.4秒で1回転する。回転中の横幅は約29.4〜34で、真横でも細い線にならない。コア・スカート形の本体後部・中心マーカーは回さない。本体後部は付け根の幅8から後端の幅22へ広がる。裾の中央を少し前に引き込み、左右の端を45度未満の鋭角に尖らせる。

ゲーム時刻を使うため、一時停止やスローに追従する。Three.jsは翼専用の立体メッシュ・輪郭線・面の目印を一度作り、回転角と色・透明度だけを更新する。毎フレームのテクスチャ生成やジオメトリ再構築は行わない。Canvasでは共有形状を同じ角度で回転して投影し、面の塗りはぼかしを使わず、輪郭の発光をまとめて描く。

全段階の機体の描画範囲は従来と同じx=-17〜17、y=-18〜19（34×37）。中心座標、バンク表現、発光範囲、Three.jsの80×80表示面と320×320テクスチャの設定は変更しない。当たり判定、かすり判定、移動速度、シールド・稲妻・中心マーカーも従来どおり。

Three.jsは色または進化段階が変わったときだけ機体テクスチャを更新し、以前のテクスチャを解放する。同じ段階内のレベルアップや通常フレームでは再生成しない。リスタートなどでレベルが戻ったときも、そのレベルに応じた形へ戻る。
